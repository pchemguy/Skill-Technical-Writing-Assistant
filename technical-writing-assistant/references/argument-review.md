# Argument review

> Status: reference skeleton. Scope and contract are established; detailed procedures, examples, and behavioral acceptance cases remain to be implemented.

## Scope and activation

Examine claims, premises, assumptions, inference, counterarguments, qualifications, contradictions, fallacies, and blind spots.

Use independently for a focused request or as a selected step in a composite workflow.

## Boundary

Assess reasoning; empirical verification belongs to evidence work. Explain the defect rather than merely attach a fallacy label.

## Inputs and missing information

Material, authorial position where known, and authorized review scope.

Reconstruct the reasoning fairly; challenge weaknesses and distinguish missing evidence from invalid inference.

## Outputs

Located findings, reasoning explanations, possible repairs, and author decisions.

## Completion checks

Criticism addresses the actual argument; proposed repairs disclose changes to scope, certainty, or conclusions.

## Optional handoffs

Use evidence-review.md for support questions and composition-exploration.md for alternatives.

Load only relevant references. A handoff does not automatically require author approval; continue within authorized scope and ask when a substantive choice remains unresolved.

## Implementation work remaining

Develop the step-by-step procedure, representative examples, failure handling, and observable acceptance cases for this contract. Do not describe this scaffold as behaviorally validated.
